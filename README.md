# 여백 미장원 웹앱

- 고객: 예약 신청, 후기 열람 및 작성
- 관리자: 대시보드, 예약·고객·코인·후기 관리
- 관리자 → 예약 관리: 월별 예약 캘린더, 이전/다음 달 및 오늘 이동, 날짜별 예약 상세 확인
- 캘린더는 현재 브라우저에 저장된 홈페이지 예약을 표시합니다. 스마트플레이스에서 접수된 예약을 가져오는 연동은 포함되어 있지 않습니다.
- 데이터: 브라우저 LocalStorage에 저장 (브라우저·PC 간 공유 안 됨)

`index.html`을 직접 열면 네이버 캘린더 연동 없이 동작합니다.

## 네이버 캘린더 연동 (예약 접수 시 원장님 캘린더에 자동 등록)

1. [네이버 개발자센터](https://developers.naver.com/apps)에서 애플리케이션 등록
   - 사용 API: **네이버 로그인**, **캘린더** (권한: 캘린더 일정 추가)
   - Callback URL: `{PUBLIC_URL}/auth/naver/callback` (예: `http://localhost:3000/auth/naver/callback`)
2. 서버 실행 (Node 18 이상)

   프로젝트 루트의 `.env` 파일에 값을 채워둡니다 (git에는 포함되지 않음):

   ```
   NAVER_CLIENT_ID=...
   NAVER_CLIENT_SECRET=...
   ADMIN_KEY=원하는-비밀키
   PORT=3000
   # 외부 배포 시: PUBLIC_URL=https://내도메인
   ```

   그 다음 실행:

   ```powershell
   node server.js
   ```
3. 원장님이 접속 → 관리자 → **네이버 캘린더 연동** → 관리자 키 입력 → 네이버 로그인 동의 (최초 1회)
4. 이후 고객이 예약하면 원장님 기본 캘린더에 `[예약] 이름 · 시술` 일정이 1시간 길이로 추가됩니다.

참고
- 토큰과 등록 이력은 `naver-store.json`에 저장됩니다 (git 제외).
- 네이버 캘린더 API는 일정 추가만 지원하므로, 예약 삭제·변경은 캘린더에 반영되지 않습니다.
- 고객이 접속하려면 서버가 외부에서 접근 가능해야 합니다 (호스팅 필요).
