# 여백 미장원 관리자 매뉴얼

매장 직원(원장·디자이너)용 운영·설치 안내입니다.

## 1. 시작하기 전에 알아둘 점

- **관리자 화면에는 로그인이 없습니다.** 상단 메뉴의 **관리자**를 누르면 누구나 열 수 있습니다. 관리자 화면은 매장 PC 등 신뢰할 수 있는 환경에서만 사용하세요. (네이버 캘린더 연동·해제만 관리자 키로 보호됩니다.)
- **데이터는 브라우저 LocalStorage에 저장**됩니다. 브라우저·PC 간에 공유되지 않으며, 사이트 데이터/캐시를 지우면 예약·고객·코인·후기가 모두 초기화됩니다.
  - 따라서 고객이 자신의 휴대폰에서 접수한 예약은 매장 PC의 관리자 화면에 나타나지 않습니다. 이 경우 네이버 캘린더 연동으로 접수 사실을 확인하세요(5장).
- 첫 실행 시 예시 데이터(고객 4명, 오늘 예약 4건, 후기 3개)가 들어 있습니다. 운영 전 필요에 맞게 삭제·정리하세요.

## 2. 실행 방법

### 방법 A. 파일 직접 열기 (연동 없음)
`index.html`을 브라우저로 엽니다. 네이버 캘린더 연동 없이 동작합니다.

### 방법 B. 서버 실행 (네이버 캘린더 연동, Node 18 이상)
```powershell
$env:NAVER_CLIENT_ID="..."; $env:NAVER_CLIENT_SECRET="..."; $env:ADMIN_KEY="원하는-비밀키"
# 외부 배포 시: $env:PUBLIC_URL="https://내도메인"
# 포트 변경 시: $env:PORT="3000"
node server.js
```
- `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `ADMIN_KEY` 중 하나라도 없으면 서버가 시작되지 않습니다.
- 기본 주소는 `http://localhost:3000` 입니다.
- 고객이 접속하려면 서버가 외부에서 접근 가능해야 합니다(호스팅 필요).

## 3. 관리자 화면 열기

1. 화면 위 메뉴의 **관리자**를 누릅니다.
2. 왼쪽 메뉴: 대시보드 / 예약 관리 / 고객 관리 / 코인 관리 / 후기 관리
3. 왼쪽 아래 **← 고객 화면으로**를 누르면 고객 화면으로 돌아갑니다.

## 4. 기능별 사용법

### 4-1. 대시보드
- 상단 카드: 오늘 예약 건수, 전체 고객 수, 발행 코인(전 고객 잔액 합계), 후기 수(숨김 후기 포함)
- **오늘의 예약**: 오늘 예약을 시간순으로 표시합니다. **전체 보기 →**로 예약 관리 이동.
- **최근 고객**: 고객 목록 앞 4명. **고객 관리 →**로 이동.

### 4-2. 예약 관리
**예약 캘린더**
- 달력의 각 날짜에 예약 건수와 앞 3건의 미리보기(시간·이름)가 표시됩니다. 3건을 넘으면 "+N건 더 보기"가 붙습니다.
- **대기** 상태 예약은 미리보기 색이 다르게 표시됩니다.
- 날짜를 누르면 아래 **날짜별 예약 상세**(시간, 이름, 시술·담당, 연락처, 상태)가 나옵니다.
- ← / → 로 월 이동(이동 시 해당 월 1일이 선택됨), **오늘**로 오늘 날짜 복귀.
- 캘린더 위에 "이번 달 예약 N건"이 표시됩니다.

**전체 예약 표**
- 예약일 기준 최신순으로 표시: 예약일, 고객(연락처), 시술(사용 코인), 담당, 상태.
- 오른쪽 **삭제** 버튼: 확인창에서 승인하면 예약이 삭제되고 해당 시간대가 다시 예약 가능해집니다.
- **+ 예약 등록**: 고객 예약 화면으로 이동합니다. 전화 예약은 이 화면에서 대신 입력하세요.

주의
- 접수된 예약의 상태는 **대기**로 시작하며, **화면에서 확정으로 바꾸는 기능은 없습니다.** 확정 안내는 고객에게 문자로 직접 보내주세요.
- 예약을 삭제해도 **사용된 코인은 자동 환불되지 않습니다.** 필요하면 코인 관리에서 **지급**으로 되돌려주세요(4-4).
- 예약 삭제·변경은 네이버 캘린더에 반영되지 않습니다(5장).

### 4-3. 고객 관리
- 고객명, 연락처, 최근 방문, 방문 횟수, 보유 코인을 표시합니다.
- 검색창에 이름 또는 연락처 일부를 입력하면 바로 필터링됩니다.
- 신규 고객은 **예약 접수 시 자동 등록**됩니다(코인 0, 최근 방문 "첫 방문 예정"). 고객을 직접 추가·수정·삭제하는 기능은 없습니다.
- 방문 횟수와 최근 방문일은 자동으로 갱신되지 않습니다.

### 4-4. 코인 관리
상단 큰 숫자는 선택한 고객의 현재 잔액입니다.

1. **고객**을 선택합니다.
2. **코인 수량**을 입력합니다.
3. 아래 세 버튼 중 하나를 누릅니다.

| 버튼 | 동작 |
| --- | --- |
| 지급 | 입력한 수량만큼 잔액에 더함 |
| 사용 | 입력한 수량만큼 잔액에서 뺌 (보유 코인 초과 시 처리되지 않음) |
| 잔액 조정 | 잔액을 입력한 수량으로 **덮어씀** |

- 처리 결과가 화면에 표시되고, **최근 코인 내역**에 기록됩니다(+ 지급 / − 사용 / = 조정, 처리 후 잔액 포함).
- **고객별 코인 잔액**에서 전체 잔액을 한눈에 볼 수 있습니다.
- 고객이 예약 시 코인으로 결제한 내역은 "예약 결제"로 자동 기록됩니다.
- 1코인 = 1원으로 시술 금액에서 차감됩니다.
- 코인 내역은 삭제할 수 없으므로 입력 전에 고객·수량을 확인하세요.

### 4-5. 후기 관리
- 모든 후기가 별점, 이름·시술, 내용, 작성일, 상태(게시 중/숨김)와 함께 표시됩니다.
- **숨기기** / **게시**: 고객 화면 노출 여부를 전환합니다. 숨긴 후기는 평균 별점·후기 수 계산에서도 빠집니다.
- **삭제**: 확인 후 영구 삭제됩니다.
- 고객이 후기를 작성하면 **즉시 게시**됩니다. 부적절한 후기는 여기서 숨기세요.

## 5. 네이버 캘린더 연동

예약이 접수되면 원장님의 네이버 기본 캘린더에 `[예약] 이름 · 시술` 일정이 **1시간 길이**로 자동 등록됩니다. 일정 설명에는 연락처, 담당, 시술 금액, 코인 사용량이 들어갑니다.

### 최초 설정
1. [네이버 개발자센터](https://developers.naver.com/apps)에서 애플리케이션을 등록합니다.
   - 사용 API: **네이버 로그인**, **캘린더** (권한: 캘린더 일정 추가)
   - Callback URL: `{PUBLIC_URL}/auth/naver/callback` (예: `http://localhost:3000/auth/naver/callback`)
2. 2장의 방법 B로 서버를 실행합니다.
3. `server.js`가 제공하는 주소(예: `http://localhost:3000`)로 접속해 **관리자 → 네이버 캘린더 연동**을 누릅니다. (파일을 직접 연 경우 동작하지 않습니다.)
4. 관리자 키(`ADMIN_KEY`)를 입력하고 네이버 로그인 후 동의합니다. 최초 1회만 하면 됩니다.

### 연동 해제
**관리자 → 연동 해제** → 관리자 키 입력. 토큰이 폐기되고 저장된 연동 정보가 삭제됩니다.

### 제한 사항
- 네이버 캘린더 API는 **일정 추가만** 지원합니다. 예약을 삭제·변경해도 캘린더 일정은 그대로 남으므로 캘린더에서 직접 정리하세요.
- 토큰과 등록 이력은 서버의 `naver-store.json`에 저장됩니다(git 제외). 이 파일을 외부에 공유하지 마세요.
- 연동이 안 되어 있거나 등록에 실패해도 예약 접수 자체는 정상 처리됩니다.
- 관리자 캘린더는 홈페이지에서 접수된 예약만 보여줍니다. 스마트플레이스 예약을 가져오는 기능은 없습니다.

## 6. 일상 운영 체크리스트

**매일**
1. 관리자 → 대시보드에서 오늘 예약 확인
2. 새 예약(대기)은 고객에게 문자로 확정 안내
3. 시술 완료 후 필요 시 코인 지급

**주기적으로**
- 후기 관리에서 부적절한 후기 숨김/삭제
- 코인 내역과 고객별 잔액 점검
- 네이버 캘린더에서 취소·변경된 예약 일정 정리

## 7. 문제 해결

| 증상 | 확인 사항 |
| --- | --- |
| 서버가 바로 종료됨 | 환경변수 3개(`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`, `ADMIN_KEY`)가 설정됐는지 확인 |
| "server.js로 실행한 주소에서만 연동할 수 있습니다" | `index.html`을 직접 연 상태입니다. `http://` 주소로 접속하세요. |
| "관리자 키가 올바르지 않습니다" | 서버 실행 시 설정한 `ADMIN_KEY`와 동일한 값을 입력 |
| 네이버 로그인 후 오류 | 개발자센터의 Callback URL이 `{PUBLIC_URL}/auth/naver/callback`과 정확히 일치하는지 확인. 로그인 시작 후 10분이 지나면 다시 시도 |
| 캘린더에 일정이 안 생김 | 관리자에서 연동 상태 확인(재연동), 서버 콘솔의 오류 메시지 확인 |
| 예약·코인 데이터가 사라짐 | 브라우저 사이트 데이터 삭제 또는 다른 브라우저 사용 여부 확인. LocalStorage 특성상 복구되지 않습니다. |
| 관리자 화면에 고객 예약이 안 보임 | 예약이 고객 기기의 브라우저에 저장된 경우입니다. 네이버 캘린더 등록 내역을 확인하세요. |

## 8. 향후 개선 권장 사항

현재 구조의 한계로 실제 운영 전 검토를 권장합니다.
- 관리자 화면 로그인/접근 제한
- 서버 DB 저장 (기기 간 예약·코인 공유, 데이터 유실 방지)
- 예약 상태 변경(대기 → 확정/취소)과 예약 삭제 시 코인 자동 환불
