# 여백 미장원 개인정보처리방침 초안 (변호사 검토용)

2026-09-27 · 초안 v0.1

## 이 문서에 대하여

변호사 검토를 받기 위한 개인정보처리방침 초안입니다. 그 자체로 법률자문이 아닙니다.

### 이용약관과의 관계

이용약관은 매장과 이용자 사이의 권리·의무를 정하는 계약입니다. 개인정보처리방침은 계약이 아니라 법정 공개 의무입니다. 개인정보를 처리하는 사업자는 이를 수립하여 공개해야 하며, 공개하지 않으면 과태료 대상입니다. 회원가입이 없는 예약 사이트라도 이름과 연락처를 받는 순간 의무가 생깁니다. 두 문서는 별개이므로 화면에서도 각각 따로 볼 수 있어야 합니다.

### 반영된 전제

| 항목 | 내용 |
| --- | --- |
| 회원가입 | 없음. 예약할 때마다 이름과 연락처를 입력 |
| 수집 항목 | 이름, 연락처, 예약 일시, 시술 메뉴, 담당 디자이너, 요청 사항, 코인 사용 내역, 후기 |
| 결제 | 현장 결제. 웹사이트에서 결제 정보를 받지 않음 |
| 알림 | 카카오톡 알림톡(실패 시 문자). 솔라피를 통해 발송 |
| 예약 캘린더 | 매장 대표자의 네이버 캘린더에 예약을 등록 |
| 서버 보관 | 방문 전날 안내용 예약 사본을 예약일로부터 30일 후 자동 삭제 |
| 매장 관리 화면 | 예약·고객·코인 정보를 매장 PC의 브라우저 저장소에 보관 |
| 후기 공개 범위 | 이름 첫 글자, 별점, 시술 메뉴, 본문, 작성일 |

[상호], [이메일] 등 대괄호 부분은 실제 정보로 채우세요.

## 제1조 개인정보의 수집 항목과 방법

[상호](이하 "매장")는 서비스 제공에 필요한 최소한의 개인정보를 다음과 같이 수집합니다.

### 예약 신청 시

| 항목 | 필수 여부 | 수집 방법 |
| --- | --- | --- |
| 이름 | 필수 | 이용자가 직접 입력 |
| 연락처(휴대전화번호) | 필수 | 이용자가 직접 입력 |
| 예약 일시, 시술 메뉴, 담당 디자이너 | 필수 | 이용자가 직접 선택 |
| 요청 사항 | 선택 | 이용자가 직접 입력 |
| 코인 사용 수량 | 선택 | 이용자가 코인 결제를 선택한 경우 |

요청 사항에는 두피 질환, 임신 여부 등 건강에 관한 정보를 적지 않도록 안내합니다. 시술에 꼭 필요한 경우 방문 시 직접 말씀해 주시면 됩니다.

### 후기 작성 시

| 항목 | 필수 여부 | 수집 방법 |
| --- | --- | --- |
| 이름 | 필수 | 이용자가 직접 입력 (첫 글자만 공개) |
| 별점, 시술 메뉴, 후기 내용 | 필수 | 이용자가 직접 입력 |

### 매장 이용 과정에서

| 항목 | 수집 방법 |
| --- | --- |
| 방문 횟수, 최근 방문일 | 매장이 기록 |
| 코인 적립·사용 내역과 잔액 | 매장이 기록 |
| 예약 상태(대기·확정·취소), 무단 불참 기록 | 매장이 기록 |
| 알림 발송 이력(종류, 발송 일시) | 서버가 자동 기록 |
| 개인정보 수집·이용 동의 이력(동의 일시, 문서 버전, 접속 IP, 브라우저 정보) | 예약 신청 시 서버가 자동 기록 |

매장은 주민등록번호, 계좌번호, 카드번호를 수집하지 않습니다.

## 제2조 개인정보의 수집·이용 목적

매장은 수집한 개인정보를 다음 목적으로만 이용하며, 목적이 변경되는 경우 사전에 동의를 받습니다.

| 목적 | 이용하는 항목 |
| --- | --- |
| 예약 접수, 확정, 변경, 취소 처리 | 이름, 연락처, 예약 일시, 시술 메뉴, 담당 디자이너, 요청 사항 |
| 예약 접수·확정·취소 및 방문 전 안내 | 이름, 연락처, 예약 일시, 시술 메뉴, 담당 디자이너, 결제 예정 금액 |
| 코인 적립과 사용, 잔액 안내 | 이름, 연락처, 코인 내역 |
| 고객 관리(방문 이력 확인) | 이름, 연락처, 방문 횟수, 최근 방문일 |
| 무단 불참 관리와 이용 제한 | 연락처, 예약 상태, 무단 불참 기록 |
| 후기 게시 | 이름(첫 글자), 별점, 시술 메뉴, 후기 내용 |
| 동의 사실의 증명과 분쟁 대응 | 동의 이력 |

광고성 정보 전송은 위 목적에 포함되지 않습니다. 매장은 이용자의 별도 동의 없이 광고성 정보를 보내지 않습니다.

## 제3조 개인정보의 보유·이용 기간

매장은 원칙적으로 개인정보 수집·이용 목적이 달성되면 지체 없이 파기합니다. 다만 다음의 경우에는 명시한 기간 동안 보관합니다.

| 항목 | 보유 기간 | 근거 |
| --- | --- | --- |
| 서버의 예약 사본(방문 전날 안내용) | 예약일로부터 30일 | 매장 방침 |
| 알림 발송 이력 | 예약일로부터 30일 | 매장 방침 |
| 매장 관리 화면의 예약·고객 정보 | 최근 방문일로부터 [3년] 또는 삭제 요청 시까지 | 매장 방침 (재방문 고객 관리) |
| 코인 내역 | 잔액 소멸 또는 삭제 요청 시까지 | 매장 방침 |
| 무단 불참 기록 | 기록일로부터 [1년] | 매장 방침 (운영정책의 이용 제한 기간) |
| 개인정보 수집·이용 동의 이력 | 동의일로부터 [3년] | 분쟁 대비 |
| 후기 | 삭제 요청 또는 게시 중단 시까지 | 매장 방침 |

## 제4조 개인정보의 제3자 제공

매장은 이용자의 개인정보를 제2조의 목적 범위를 넘어 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있거나 수사기관이 법령에 정한 절차에 따라 요청하는 경우에는 예외로 합니다.

## 제5조 개인정보 처리의 위탁

매장은 서비스 제공을 위하여 다음과 같이 개인정보 처리 업무를 위탁합니다.

| 수탁자 | 위탁 업무 | 처리 항목 |
| --- | --- | --- |
| [주식회사 솔라피] | 카카오톡 알림톡 및 문자 발송 대행 | 이름, 연락처, 예약 일시, 시술 메뉴, 담당 디자이너, 결제 예정 금액 |
| [주식회사 카카오] | 카카오톡 알림톡 전송 | 연락처, 알림 내용 |
| [네이버 주식회사] | 매장 예약 일정 관리(네이버 캘린더) | 이름, 연락처, 예약 일시, 시술 메뉴, 담당 디자이너, 시술 금액, 코인 사용 수량 |
| [호스팅 사업자명] | 웹사이트 서버 운영 | 서버에 보관되는 예약 사본, 동의 이력 |

매장은 위탁계약 시 개인정보가 안전하게 처리되도록 필요한 사항을 규정하고, 수탁자가 이를 지키는지 감독합니다. 수탁자가 바뀌면 이 방침을 통해 알립니다.

## 제6조 개인정보의 국외 이전

매장은 개인정보를 국외로 이전하지 않습니다. 수탁자의 서버가 국외에 있는 것으로 확인되면 이 조를 수정하여 이전받는 자, 이전 국가, 이전 항목과 거부 방법을 알립니다.

## 제7조 개인정보의 파기 절차와 방법

1. 보유 기간이 지나거나 처리 목적이 달성된 개인정보는 지체 없이 파기합니다.
2. 서버에 저장된 예약 사본과 알림 발송 이력은 예약일로부터 30일이 지나면 자동으로 삭제됩니다.
3. 매장 관리 화면의 정보는 매장이 정기적으로 점검하여 보유 기간이 지난 정보를 삭제합니다.
4. 전자적 파일 형태의 정보는 복구할 수 없는 방법으로 삭제합니다. 종이에 출력한 정보는 분쇄하거나 소각합니다.

## 제8조 후기의 공개와 삭제

1. 후기는 누구나 볼 수 있는 화면에 게시됩니다. 작성자 이름은 첫 글자만 공개하고 나머지는 가려서 표시합니다.
2. 후기 본문에 이름, 연락처 등 개인을 알아볼 수 있는 정보를 적지 않도록 안내합니다. 이런 정보가 포함된 후기는 매장이 숨길 수 있습니다.
3. 이용자는 자신이 작성한 후기의 삭제를 매장에 요청할 수 있으며, 매장은 본인 여부를 확인한 뒤 지체 없이 삭제합니다.

## 제9조 정보주체의 권리와 행사 방법

1. 이용자는 매장에 대하여 언제든지 개인정보의 열람, 정정, 삭제, 처리정지를 요청할 수 있습니다.
2. 요청은 매장 전화([대표 번호]), 전자우편([이메일]) 또는 매장 방문으로 할 수 있으며, 매장은 본인 여부를 확인한 뒤 10일 이내에 조치합니다.
3. 대리인을 통하여 요청하는 경우 위임장을 제출하여야 합니다.
4. 삭제를 요청하는 경우 해당 이용자의 코인 잔액도 함께 소멸될 수 있으며, 매장은 삭제 전에 이를 안내합니다.

## 제10조 만 14세 미만 아동의 개인정보

매장은 만 14세 미만 아동으로부터 직접 개인정보를 수집하지 않습니다. 만 14세 미만 아동의 시술 예약은 법정대리인이 자신의 이름과 연락처로 신청하도록 안내합니다.

## 제11조 개인정보의 안전성 확보 조치

1. 관리자 화면은 비밀번호를 입력해야 열 수 있습니다.
2. 서버의 예약 사본 파일은 서버 운영 계정만 읽을 수 있도록 권한을 제한합니다.
3. 웹사이트는 암호화된 연결(HTTPS)로 제공합니다.
4. 관리자 화면이 열린 PC는 자리를 비울 때 로그아웃합니다.

## 제12조 자동 수집 장치의 설치·운영 및 거부

1. 매장은 쿠키를 사용하지 않습니다.
2. 서비스는 이용자의 브라우저 저장소(localStorage)에 예약 화면 표시에 필요한 정보를 저장합니다. 이용자는 브라우저 설정에서 사이트 데이터를 삭제하여 이를 지울 수 있습니다.

3. 수집 항목이나 이용 목적이 늘어나는 등 중대한 변경이 있는 경우에는 시행 30일 전부터 공지합니다.

## 부록 A. 서비스 개시 전에 채워야 할 항목

아래가 비어 있거나 사실과 다르면 과태료 대상입니다.

| 항목 | 위치 | 현재 상태 |
| --- | --- | --- |
| 상호 | 제1조 | 미기재 |
| 알림 발송 대행사 | 제5조 | 솔라피로 구현됨. 계약 주체명 확인 필요 |
| 호스팅 사업자 | 제5조 | 미기재 — 서버 위치가 국외면 제6조 수정 |
| 대표 번호, 전자우편 | 제9조, 제13조 | 화면의 031-123-4567은 예시 번호 |
| 개인정보 보호책임자 | 제13조 | 미기재 — 1인 사업장이면 대표자 |
| 시행일자 | 제15조, 부칙 | 미기재 — 서비스 개시일 |
| 관리 화면 정보 보유 기간 | 제3조 | [3년] 가정 — 실제로 지울 수 있는 기간으로 정할 것 |

### 함께 정해야 할 사항

1. **관리 화면 데이터의 파기.** 서버 사본은 30일 뒤 자동 삭제되지만, 매장 PC 브라우저에 쌓이는 고객·예약 정보는 자동으로 지워지지 않습니다. 방침에 쓴 보유 기간을 지키려면 삭제 기능을 만들거나 매달 수동 점검을 운영 체크리스트에 넣어야 합니다.
2. **예약자 브라우저의 데이터.** 현재 앱은 예약자 본인의 브라우저에도 예약 정보를 저장합니다. 공용 PC에서 예약하면 다음 사용자가 볼 수 있습니다. 서버 DB로 옮기면(기능 설계서 A-1) 이 문제가 사라집니다.
3. **네이버 캘린더.** 예약이 대표자 개인 네이버 계정 캘린더에 들어갑니다. 계정을 가족과 공유하거나 휴대폰 알림에 내용이 뜨는 경우도 개인정보 노출입니다. 매장 전용 계정 사용을 권합니다.
4. **광고성 알림.** 신규 메뉴, 할인 안내를 보내려면 예약 화면에 별도 선택 동의를 추가해야 합니다. 예약 필수 동의에 묶으면 무효입니다.

## 부록 B. 검토 포인트와 구현 체크리스트
