# 여백 미장원 운영정책 초안

2026-09-27 · 초안 v0.1

## 이 문서에 대하여

이용약관이 "운영정책으로 정한다"고 위임한 기준을 담는 문서입니다. 약관이 뼈대라면 이 문서는 매장에서 실제로 돌아가는 규칙입니다.

### 공개해야 효력이 생깁니다

약관 여러 조항이 이 문서를 참조합니다. 참조만 해놓고 실체가 없으면 해당 조항들이 근거를 잃습니다. 특히 노쇼로 온라인 예약을 제한하려면 그 기준이 미리 공개되어 있어야 합니다. 고객이 알 수 없었던 기준으로 제한하면 다툼의 대상이 됩니다.

### 공개용과 내부용을 나눕니다

- 공개: 예약 운영 기준, 변경·취소·노쇼 기준, 코인 적립 사유, 후기 운영 기준, 알림 안내
- 내부: 코인 적립 수량, 개인정보 열람 원칙, 운영자 행동 원칙

공개 부분은 웹사이트의 "운영정책" 화면에 그대로 게시합니다.

| 약관 조항 | 위임한 내용 |
| --- | --- |
| 제4조 | 약관에 없는 사항 |
| 제6조 제3항 | 예약 거절 사유 |
| 제8조 | 무단 불참과 지각 처리 |
| 제9조 제3항 | 코인 적립 사유와 기준 |
| 제13조 | 후기 숨김·삭제 기준 |
| 제16조 | 이용 제한의 구체적 기준 |

## 제1장 예약 운영 (공개)

### 예약 가능 시간

1. 예약은 영업시간 10:00 — 20:00 안에서 30분 단위로 받습니다.
2. 이미 예약된 시간은 화면에 "예약 완료"로 표시되며 선택할 수 없습니다.
3. 휴무일과 매장 사정으로 영업하지 않는 날은 예약을 받지 않습니다.

### 진행 순서

```
예약 신청 → 접수 안내(알림톡) → 매장 확인 → 확정 또는 거절 안내(알림톡) → 방문 전날 안내(알림톡) → 방문
```

1. 매장은 영업시간 중 접수된 예약을 당일 안에, 영업시간 외 접수된 예약은 다음 영업일 오전 중에 확인합니다.
2. 확정 안내를 받기 전에는 예약이 확정되지 않은 상태입니다.

### 예약 거절 사유

1. 같은 시간에 이미 다른 예약이 확정된 경우
2. 연락처가 잘못되어 연락이 되지 않는 경우
3. 선택한 시술이 해당 시간 안에 끝나기 어려운 경우 (다른 시간을 안내합니다)
4. 제2장에 따른 온라인 예약 제한 기간 중인 경우
5. 매장 사정으로 해당 일시에 영업하지 않는 경우

## 제2장 변경·취소·노쇼 (공개)

### 변경과 취소

| 시점 | 처리 |
| --- | --- |
| 예약일 전날까지 | 전화로 변경·취소 가능. 불이익 없음 |
| 예약 당일 예약 시각 전 | 전화로 취소 가능. 불이익 없음. 가능하면 미리 알려주세요 |
| 연락 없이 방문하지 않음 | 무단 불참으로 기록 |

매장은 예약금을 받지 않으므로 취소 위약금이 없습니다. 취소된 예약에 사용하기로 한 코인은 반환합니다.

### 지각

| 도착 시각 | 처리 |
| --- | --- |
| 예약 시각 후 15분 이내 | 예정대로 시술. 다음 예약이 있으면 시술 내용이 조정될 수 있음 |
| 15분 초과 30분 이내 | 매장과 협의하여 시술 내용 조정 또는 다른 시간으로 변경 |
| 30분 초과, 연락 없음 | 무단 불참으로 처리 |

### 무단 불참과 온라인 예약 제한

무단 불참이 쌓이면 웹사이트를 통한 예약만 제한합니다. 전화 예약은 제한하지 않습니다.

| 무단 불참 횟수 (최근 1년) | 조치 |
| --- | --- |
| 1회 | 안내 문자 |
| 2회 | 30일간 온라인 예약 제한 |
| 3회 이상 | 90일간 온라인 예약 제한 |

1. 매장 사정이나 불가피한 사고(질병, 사고 등)로 불참한 경우 증빙 없이도 사정을 말씀해 주시면 기록에서 제외합니다.
2. 무단 불참 기록은 기록일로부터 1년이 지나면 삭제합니다.
3. 제한 조치에 이의가 있으면 매장에 연락해 주세요. 매장은 3일 이내에 검토 결과를 알려드립니다.

## 제3장 코인 (적립 사유 공개, 수량 내부)

### 적립 사유 (공개)

1. 시술 완료 시 적립
2. 첫 방문 적립
3. 매장 이벤트 참여
4. 매장 착오로 인한 불편에 대한 보상

적립 수량은 매장 공지와 방문 시 안내로 알려드립니다. 후기 작성에 대하여 코인을 적립하는 경우, 해당 후기에 "코인 적립 이벤트 참여 후기"임을 표시합니다.

### 사용 기준 (공개)

1. 1코인은 1원으로 계산합니다.
2. 예약할 때 연락처를 입력하면 보유 코인이 표시되며, 시술 금액 안에서 사용할 수 있습니다.
3. 예약이 취소되면 사용하기로 한 코인을 반환합니다.
4. 코인은 현금으로 바꿀 수 없고, 다른 사람에게 넘길 수 없습니다.

### 적립 수량 (내부)

| 사유 | 수량 | 비고 |
| --- | --- | --- |
| 시술 완료 | [시술 금액의 N%] | 현재 예시 데이터: 2,500 C |
| 첫 방문 | [미정] | |
| 이벤트 | 이벤트별 공지 | |
| 불편 보상 | 원장 판단, [상한] 이하 | 사유를 코인 내역에 기록 |

### 기록 (내부)

- 코인 관리 화면에서 지급·사용·잔액 조정을 할 때마다 내역이 남습니다. "잔액 조정"은 사유를 알 수 없으므로 착오 정정에만 쓰고, 정정 사유는 별도 운영 기록에 남깁니다.
- 적립 기준을 바꾸면 변경일과 내용을 기록합니다. 같은 사유로 고객마다 다른 수량을 적립하면 불공정 시비가 생깁니다.

## 제4장 알림 (공개)

| 종류 | 보내는 시점 | 내용 |
| --- | --- | --- |
| 접수 안내 | 예약 신청 직후 | 예약 일시, 시술, 결제 예정 금액 |
| 확정 안내 | 매장이 확정할 때 | 위와 같음 |
| 취소 안내 | 매장이 취소를 처리할 때 | 위와 같음 |
| 방문 전 안내 | 방문 전날 오전 10시 이후 1회 | 위와 같음 |

1. 알림은 카카오톡 알림톡으로 보내고, 받을 수 없는 경우 문자로 보냅니다.
2. 알림에는 광고나 할인 홍보를 넣지 않습니다.
3. 방문 전 안내는 확정 안내를 받은 예약에만 보냅니다.

## 제5장 후기 운영 기준 (공개)

### 게시 원칙

1. 후기는 작성 즉시 게시됩니다.
2. 작성자 이름은 첫 글자만 공개합니다.
3. 낮은 별점이나 시술에 대한 불만이라는 이유만으로 후기를 숨기거나 삭제하지 않습니다.
4. 매장은 후기를 수정하지 않습니다. 사실과 다른 부분이 있으면 매장이 답변을 남기는 방식으로 대응합니다. (답변 기능 도입 시)

### 숨김·삭제 기준

| 상황 | 조치 |
| --- | --- |
| 다른 사람의 이름, 연락처, 사진 등 개인정보 노출 | 숨김 후 작성자가 요청하면 수정본으로 재게시 |
| 욕설, 음란한 표현, 특정인 모욕·명예훼손 | 삭제 |
| 광고, 다른 업체 홍보, 시술과 무관한 내용 | 삭제 |
| 시술을 받지 않고 작성한 것이 명백한 경우 | 삭제 |
| 같은 사람이 같은 내용을 반복 게시 | 1건만 남기고 삭제 |
| 작성자 본인의 삭제 요청 | 본인 확인 후 삭제 |

숨김·삭제할 때는 날짜, 사유, 조치 내용을 운영 기록에 남깁니다.

## 제6장 개인정보 관리 원칙 (내부)

1. 관리자 화면은 원장과 [지정한 직원]만 사용합니다. 비밀번호는 공유 메신저에 적지 않습니다.
2. 고객 연락처는 예약 안내와 코인 안내에만 사용합니다. 개인 휴대폰으로 연락하거나 저장하지 않습니다.
3. 매월 첫 영업일에 관리 화면의 고객 목록을 점검하고, 최근 방문일로부터 [3년]이 지난 고객 정보를 삭제합니다.
4. 고객이 정보 삭제를 요청하면 관리 화면의 고객·예약·코인 기록을 지우고, 코인 잔액이 있으면 삭제 전에 안내합니다.
5. 예약이 등록되는 네이버 캘린더는 매장 전용 계정을 사용하고, 가족과 공유하지 않습니다.
6. 수사기관의 자료 요청은 영장 등 법적 근거를 확인한 뒤 필요한 범위만 제공하고, 제공 내역을 기록합니다.

## 제7장 운영자 행동 원칙 (내부)

### 해도 되는 것

- 확정 전 고객에게 전화로 시술 내용과 소요 시간 확인
- 노쇼 고객에게 1회 안내 문자
- 후기에 대한 감사 인사(답변 기능 도입 시)

### 하면 안 되는 것

| 금지 | 이유 |
| --- | --- |
| 직원이나 지인에게 후기 작성을 부탁 | 표시광고법상 기만적 표시 |
| 코인을 돈을 받고 판매 | 전자금융거래법 적용 가능성. 약관 전제가 깨짐 |
| 알림톡에 할인·홍보 문구 추가 | 광고성 정보 무단 전송 |
| 낮은 별점 후기 숨김 | 후기 조작으로 볼 여지 |
| 고객 연락처로 개인적인 연락 | 목적 외 이용 |
| 고객 정보를 화면 캡처해 메신저로 공유 | 유출 |

## 부록 C. 시행 전 확정할 것

1. 코인 적립 수량과 유효기간
2. 무단 불참 제한 단계(횟수와 기간)가 매장 규모에 맞는지
3. 휴무일 표시 방법 — 현재 화면에는 휴무일 기능이 없음 (기능 설계서 C-2)
4. 노쇼 기록 방법 — 현재 예약 상태에 "불참" 값이 없음. 추가 필요
5. 앱 화면의 예시 데이터 정리 — 후기 3건, 고객 4명, 코인 내역은 예시
