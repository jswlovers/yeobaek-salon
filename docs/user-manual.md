# 여백 미장원 사용자 매뉴얼 (고객용)

여백 미장원 웹앱에서 예약하고, 코인으로 결제하고, 후기를 남기는 방법을 안내합니다.

## 1. 화면 구성

화면 위쪽 메뉴에서 이동합니다.

| 메뉴 | 내용 |
| --- | --- |
| 홈 | 매장 소개, 오늘 예약 상태, 운영 시간(10:00 — 20:00), 문의 전화 |
| 예약 | 날짜·시간 선택 후 예약 신청 |
| 후기 | 다른 고객의 후기 보기, 후기 작성 |
| 관리자 | 매장 직원 전용 화면 (고객은 사용하지 않습니다) |

모바일에서는 오른쪽 위 **예약하기** 버튼으로 바로 예약 화면에 갈 수 있습니다.

## 2. 예약하기

### 2-1. 날짜 선택
1. **예약** 메뉴를 누릅니다.
2. 왼쪽 달력에서 원하는 날짜를 누릅니다. 지난 날짜는 선택할 수 없습니다.
3. ← → 버튼으로 달 이동이 가능합니다. (현재 달 이전으로는 이동할 수 없습니다.)

### 2-2. 시간 선택
- 날짜를 고르면 오른쪽에 **30분 단위**(10:00 ~ 19:30) 시간표가 나타납니다.
- 선택 가능한 시간은 **예약 가능**, 이미 찼거나 선택할 수 없는 시간은 **예약 완료**(회색)로 표시됩니다.
- 원하는 시간을 누르면 선택 상태가 됩니다.

### 2-3. 예약자 정보 입력
| 항목 | 설명 |
| --- | --- |
| 이름 | 필수 |
| 연락처 | 필수. 예: 010-0000-0000. 입력하면 보유 코인이 자동으로 표시됩니다. |
| 시술 메뉴 | 필수. 여성 커트 35,000원 / 남성 커트 25,000원 / 프리미엄 염색 120,000원 / 디자인 펌 150,000원 / 클리닉 케어 80,000원 |
| 담당 디자이너 | 지정 없음, 서윤 원장, 하린 디자이너, 도윤 디자이너 |
| 요청 사항 | 선택. 원하는 스타일이나 참고 사항 |

### 2-4. 코인으로 결제하기 (선택)
1. **코인으로 결제하기**를 체크합니다.
2. **사용할 코인**에 수량을 입력하거나 **최대 사용**을 누릅니다.
3. 아래 요약 문구에서 `시술 금액 · 코인 · 현장 결제` 금액을 확인합니다.

주의
- 등록된 고객(이전에 방문하여 연락처가 등록된 고객)만 코인을 사용할 수 있습니다.
- 보유 코인보다 많이, 또는 시술 금액보다 많이 사용할 수 없습니다.
- 남은 금액은 **매장에서 현장 결제**합니다.
- 코인은 예약 신청 시점에 바로 차감됩니다.

### 2-5. 예약 신청
**예약 및 결제 신청**을 누르면 "예약이 접수되었습니다" 창에 일시, 시술, 사용 코인, 남은 코인, 현장 결제 예정 금액이 표시됩니다. **확인**을 누르면 홈으로 돌아갑니다.

- 접수 직후 예약 상태는 **대기**입니다. 확정 여부는 매장에서 문자로 안내합니다.
- 방금 다른 예약이 들어와 시간이 찼다면 "방금 예약된 시간입니다" 안내가 뜹니다. 다른 시간을 선택해주세요.

### 예약 안내
- 예약 변경·취소는 **하루 전까지** 매장(031-123-4567)으로 연락해주세요. 웹앱에는 고객용 예약 변경·취소 기능이 없습니다.
- 시술 시간은 모발 상태에 따라 달라질 수 있습니다.

## 3. 후기 보기와 작성

### 후기 보기
**후기** 메뉴에서 평균 별점, 후기 개수, 후기 목록을 볼 수 있습니다. 작성자 이름은 첫 글자만 표시됩니다(예: 김**).

### 후기 작성
1. **후기** 메뉴에서 **후기 작성**을 누릅니다.
2. 이름, 별점(3~5점), 시술 메뉴, 후기 내용을 입력합니다.
3. **후기 등록하기**를 누르면 바로 게시됩니다.
4. 창 바깥이나 × 버튼을 누르면 작성이 취소됩니다.

게시된 후기는 매장 관리자가 숨기거나 삭제할 수 있습니다.

## 4. 자주 묻는 질문

**Q. 내 보유 코인은 어디서 확인하나요?**
예약 화면에서 연락처를 입력하면 입력창 아래에 표시됩니다. 등록되지 않은 연락처는 0 C로 표시됩니다.

**Q. 시간표에 원하는 시간이 회색이에요.**
이미 예약된 시간입니다. 같은 시간에는 한 건만 접수됩니다. 다른 시간이나 날짜를 선택해주세요.

**Q. 예약을 바꾸거나 취소하고 싶어요.**
하루 전까지 매장으로 전화해주세요.

**Q. 다른 기기에서 예약 현황이 다르게 보여요.**
현재 버전은 예약 데이터를 사용 중인 브라우저에 저장합니다. 브라우저·기기마다 화면이 다를 수 있으니, 정확한 예약 확정은 매장의 문자 안내를 기준으로 해주세요.
